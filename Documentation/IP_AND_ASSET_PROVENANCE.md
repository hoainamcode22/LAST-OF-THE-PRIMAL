# PRIMAL FRONTIER - IP and asset provenance log

Purpose: keep a record of where every shipped asset comes from, so the game stays original and legally clean.
Update this file whenever an asset is added.

## Rules (apply to every asset)

1. No asset (model, skeleton, animation, texture, sound, music, font, icon, UI graphic, text) is taken from ARK or any other game.
2. Reference images are used for quality direction only. They are stored in `Documentation/References/` for internal use and
   are never shipped, traced or textured from.
3. Do not reuse other games' distinctive elements: UI layouts and ornaments, item / quest names, logos, creature designs,
   colour schemes, signature silhouettes, sound effects.
4. Third-party material is allowed only with a licence that permits commercial use (CC0 preferred). The licence text is stored
   next to the source in `E:\Model game khủng long\thirdparty\`.
5. Every creature is an original design (own proportions, head shape, skin pattern, colours). Real dinosaur species are
   public-domain science; specific game or film renditions are not.
